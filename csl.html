📝 Setup Guide

CustomSkinLoader Setup

Follow these steps to install CustomSkinLoader in Sozip Launcher and use custom skins.

Download CustomSkinLoader.json

Step-by-Step Guide

  1. Download the CustomSkinLoader Mod
  2. Launch the game from Sozip Launcher and join any world once to initialize the mod folder structure.
  3. Navigate to the folder: sozip_data\instances\version\CustomSkinLoader (a new folder will be created automatically after launching the mod).
  4. Inside that folder, locate the CustomSkinLoader.json file. If it exists, delete it.
  5. Move the downloaded CustomSkinLoader.json file into this folder.
  6. Now you can upload your custom skins via Ely.by or place skin files in the LocalSkins folder with your username.
  7. Launch the game again, and your custom skins should appear in-game.
