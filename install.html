Install Sozip Launcher

A free and open-source Minecraft launcher developed by sozip19op under the GNU General Public License v3. Choose your setup method below.

⚠️

Windows Defender / SmartScreen Notice

Microsoft Defender may flag our executable as untrusted because it lacks an expensive digital code-signing certificate. To make installation fast and hassle-free, we provide these direct command-line installer scripts.

🪟 Windows Setup

Open Command Prompt (cmd) or PowerShell and run:
powershell -NoProfile -ExecutionPolicy Bypass -Command "iwr https://raw.githubusercontent.com/sozipp/sozip-launcher/main/install-scripts/v2.0/SOZIP-Launcher-Setup-Windows.bat -OutFile sozip-setup.bat; & .\sozip-setup.bat"

🐧 Linux Setup

Open your Terminal and execute:
curl -fsSL https://raw.githubusercontent.com/sozipp/sozip-launcher/main/install-scripts/v2.0/sozip-launcher-setup-linux.sh -o sozip-setup.sh && bash sozip-setup.sh

📦 Run directly from Source Code

If you prefer running Sozip Launcher directly from the raw source code, follow these steps:

  1. Ensure Python is installed on your system.
  2. Go to our GitHub repository and open the source/$versionyouwant$ folder you wish to download.
  3. Copy the folder URL from your browser bar and paste it into download-directory.github.io to download the target folder as a .zip file.
  4. Extract the .zip file contents into a dedicated, empty folder on your system.
  5. Run the launcher startup script inside that folder: .bat for Windows or .sh for Linux.
💡 Folder & Uninstall Info: All launcher assets, data, and Minecraft game files are self-contained inside the directory where you extracted the files. To uninstall Sozip Launcher completely, simply delete the folder!
