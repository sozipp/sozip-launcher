# SOZIP Launcher

A modern Minecraft launcher focused on simplicity, customization, mod support, and an easy-to-use experience.

> **SOZIP Launcher is an independent community project and is not affiliated with, endorsed by, or sponsored by Mojang Studios or Microsoft.**

---

## ✨ Features

- 🎮 Minecraft instance management
- 🧩 Mod support
- 📦 Modpack support
- 🔧 Fabric, Forge, and NeoForge support
- 🌐 Mod discovery through Modrinth
- 🖥️ Minecraft server management
- 🎨 Custom skins
- ☕ Java management
- 💾 RAM/JVM configuration
- 🔌 Plugin management
- 🛠️ Crash-assistant integration
- 📥 Automatic downloads and installation
- 🌙 Modern dark-themed interface
- ⚡ Background downloading to keep the launcher responsive
- 🔐 Ely.by authentication support
- 📊 System information and resource monitoring

The launcher can automatically retrieve compatible Minecraft content and files from supported services. For example, its code integrates with Modrinth for mod/plugin discovery and downloads.
